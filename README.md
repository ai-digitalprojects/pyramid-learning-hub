# מסע אל הפירמידה

**לומדים, חוקרים ובונים** · הנדסה לכיתה ו׳ | בית ספר גבים

אתר לימודי אינטראקטיבי בעברית על פירמידות: הכרת הגוף, מרכיביו, פריסות, וחישוב נפח.

---

## איך פותחים את האתר

**הדרך הפשוטה:** לוחצים לחיצה כפולה על `index.html`. הוא נפתח בדפדפן — אין צורך בהתקנה
או בשרת. האתר בנוי בלי מודולים ובלי טעינת קבצים ברקע, ולכן הוא עובד גם כשפותחים אותו כך.

> אם הדפדפן חוסם שמירה מקומית בקבצים שנפתחים ישירות מהמחשב, האתר יציג על כך הודעה בעברית
> וימשיך לעבוד — אבל ההתקדמות תישמר רק עד סגירת הדף.

**הדרך המומלצת לבדיקה מלאה** (כולל שמירת התקדמות), מתוך תיקיית הפרויקט:

```
python -m http.server 8777
```

ואז פותחים בדפדפן: `http://127.0.0.1:8777/`

**בפרסום:** האתר מתפרסם דרך GitHub Pages משורש המאגר (החלטה D1), ושם הכול עובד במלואו.

```

.nojekyll               מונע עיבוד מיותר של GitHub Pages
.gitignore              מוציא מה-Git את חומרי המקור המוגנים

    tokens.css          צבעים, גופנים, מרווחים — מקור אמת יחיד
    base.css            איפוס, ברירות מחדל RTL, טיפוגרפיה
    components.css      כרטיסים, כפתורים, פסי התקדמות, טבלאות
    activities.css      סגנונות הפעילויות
    kit.css             רכיבי מנוע הפעילויות
    home.css            דף הבית: נוף הכותרת, כרטיסי המסע ומסך הסיום
    tools.css           ארגז הכלים, מבחן הסיום והתעודה
  js/
    geometry/
      pyramid-geometry.js   מקור האמת הגאומטרי של האתר
      solid-view.js         מציג גופים ב-SVG, עם הסתרת קווים
      net-view.js           פריסות ואנימציית הקיפול
    activity-kit.js     מנוע הפעילויות המשותף וחוזה הלמידה
    shapes.js           גופים מיוחדים (חרוט, תיבה, פירמידה קטומה…)
    icons.js            סמלי SVG מקוריים
    scene.js            נוף המדבר של דף הבית, מצויר בקוד
    figures.js          איורים מורכבים לשאלות מילוליות
    celebrate.js        מסך הסיום החגיגי של יחידה
    store.js            שמירת התקדמות ב-localStorage
    ui.js               עזרי תצוגה, הכרזות לקוראי מסך
    router.js           ניתוב לפי hash
    main.js             הרכבה ואתחול
    views/              דף הבית, יחידה, פעילות, התקדמות, ארגז הכלים, מבחן סיום

data/
  strings.he.js         כל מחרוזות הממשק
  unit-1.js             תשע פעילויות יחידה 1
  unit-2.js             אחת־עשרה פעילויות יחידה 2

  PROJECT-SPEC.md       המפרט המלא וההחלטות

  ASSET-PROVENANCE.md   מקור כל נכס ורישיונו
```

רוב הפעילויות מונעות נתונים: הן מתוארות בקובצי `data/` ומורצות על ידי `activity-kit.js`.
רק שש פעילויות שדורשות התנהגות מיוחדת ממומשות בנפרד ב-`assets/js/activities/`.

## עריכת תוכן בלי לגעת בקוד

כל הטקסטים בממשק נמצאים ב-`data/strings.he.js`, וכל הפעילויות ב-`data/unit-1.js`
ו-`data/unit-2.js`. אפשר לתקן שם ניסוח בעברית ולרענן את הדפדפן.

---

## זכויות יוצרים

חומרי המקור בתיקייה `source-materials/` משמשים **כהפניה פדגוגית בלבד**. כל האיורים,
המודלים, השאלות, הנתונים המספריים וההסברים באתר הם מקוריים. אין באתר סריקות, אין
העתקות של איורים ואין שאלות מועתקות מילה במילה.

התיקייה `source-materials/` וכל קובץ PDF מוחרגים ב-`.gitignore` ואינם נכנסים להיסטוריית
ה-Git ואינם מתפרסמים.

## מה יש באתר

* **יחידה 1 — הכרת הפירמידה:** תשע פעילויות, מזיהוי הגוף ועד פריסות וקיפול.
* **יחידה 2 — חישוב נפח פירמידה:** אחת־עשרה פעילויות, מזיהוי הגובה ועד בעיות מהחיים.
* **ארגז הכלים:** מודל תלת־ממדי, פריסה מתקפלת, כרטיס הנוסחה ומילון מונחים.
* **ההתקדמות שלי:** התקדמות בשתי היחידות ובמבחן הסיום.
* **מבחן סיום:** שתים־עשרה שאלות, עוברים עם תשע, ותעודת סיום.

סך הכול 102 שאלות בפעילויות ועוד 12 במבחן הסיום.
